# LoyalPay Architecture Document Pack

This folder contains graph-ready design artifacts for LoyalPay.

## How to Render

- Mermaid files (`.mmd`) can be rendered in Mermaid Live Editor or VS Code Mermaid preview.
- DBML file (`.dbml`) can be rendered at dbdiagram.io.
- SQL schema (`.sql`) can be used in SQL tools and ER generators.

## Folder Structure

- `HLD/` High-level design documents
- `LLD/` Low-level design documents
- `Diagrams/` Architecture, flowchart, class, ER and solution diagrams
- `Database/` Schema definition and relational model
